## CADAI 智能助手

### 功能介绍
- **AI 智能对话**：独立 AI 对话浮动窗口，支持自由缩放与跨屏拖动、长会话上下文压缩与历史记录恢复。
- **自然语言 CAD 交互**：通过自然语言完成 CAD 图元查询、修改、统计、绘制、实体几何变换与图层管理。
- **工程标注与 MCP 工具集**：内置涵盖查询、绘制、编辑、标注、文字排版、图块、布局、Excel/PDF 与批处理的专业 `cad_*` MCP 工具。
- **弹窗看门狗（ModalAgent）**：独立进程外弹窗监控与安全自动应答，防止自动化执行被 AutoCAD 模态弹窗阻塞。
- **工程安全保障**：支持单轮原子撤销（Ctrl+Z 撤回整轮修改），交互过程安全透明。
